Emergent

A synthetic ethology platform for ESP32-class hardware — behavior from homeostasis, memory, and embodiment, not scripts or big models.

no cloud inference no behavior tree runs on-device

This project builds small, battery-powered machines whose behavior emerges from a body model, drifting internal drives, a decaying contingency memory, and a coarse spatial map — all running directly on an ESP32. The full design rationale, historical background, and algorithms are written up in the synthetic behavior paper below.
