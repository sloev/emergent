Contingency

What the board has learned so far: patterns of "actuators moved like this, sensors moved like that" and whether that pattern coincided with falling drive pressure (Δdrive, higher is better). Strongest entries first. The action generator queries this every tick to bias its next move toward whatever has helped before.

Places

This board has no positioning sensor, so a "place" is a coarse signature of current sensor readings — same ambient conditions read as the same place. Each square is one remembered place; brighter = more promising for what's pressing right now. There's no direction to steer in without real coordinates, so this only widens or narrows the action generator's exploration noise — wider if a better place than "here" is known, narrower if "here" already looks best.

The organism's physiology, contingency memory, and spatial memory as one file (docs/synth-behavior.md §13) — download it, and it can be restored later, even onto a different board. Channels are matched by name: anything that doesn't exist on the board you restore onto is quietly dropped rather than causing an error.
